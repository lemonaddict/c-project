## How to try
1. **Using Windows**
    - **VS Code + GCC (MinGW):**
        1. Clone or copy the project files.
        2. Open a terminal in the project directory.
        3. Run:
           ```sh
           gcc -o output/main-rpg.exe main.c file_io.c game.c
           ```
        4. Run the game with:
           ```sh
           .\output\main-rpg.exe
           ```
    - **Dev C++:**
        1. Clone or copy the project files.
        2. Open the project in Dev C++.
        3. Click "Compile & Run" or press F11.
